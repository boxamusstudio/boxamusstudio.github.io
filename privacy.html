Privacy Policy – BoXaMusYT

Last updated: October 24, 2026

BoXaMusYT is a private tool operated by BoXaMus. It is used only by the owner of the BoXaMus YouTube channel to manage that channel.

What data the app uses

When the owner signs in with Google, the app gets an access token for the YouTube Data API. The app uses this token only to upload videos, update video details, and manage playlists and subscriptions on the owner's own YouTube channel.

How data is stored

OAuth tokens are stored only on the owner's own computer. The app does not have a server and does not keep a database of users.

Sharing

The app does not sell, share, or transfer Google user data to any third party. It does not use Google user data for advertising.

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke the app's access at any time at myaccount.google.com/permissions.
